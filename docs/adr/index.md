# Architecture Decision Record Compendium

This compendium collects every accepted Architecture Decision Record for the Cookbook and Shopping Planning application. ADRs explain durable design choices and their trade-offs; acceptance does not imply that the described behavior is implemented. Use the companion [Developer and Operator Guide](file:developer-guide-en.pdf) for current repository evidence, planned capability context, and the dependency-ordered implementation roadmap.

The records follow identifier order. Later ADRs and recorded documentation decisions may clarify an earlier choice without erasing its historical context.
